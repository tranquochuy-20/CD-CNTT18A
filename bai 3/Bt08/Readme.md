# BÀI THỰC HÀNH 08 - NODEJS MODULE FS

## 1. Thông tin bài tập

- Họ và tên: Huy Trần
- Lớp: CD-CNTT18A
- Môn học: NodeJS
- Bài thực hành: Bài 08

## 2. Mục tiêu

- Sử dụng module fs của NodeJS.
- Tạo thư mục data.
- Tạo tập tin ghichu.txt và ghi ít nhất 3 dòng nội dung.
- Đổi tên tập tin bằng fs.rename().
- Đọc nội dung tập tin sau khi đổi tên.
- Tạo và xóa tập tin tam.txt bằng fs.unlink().

## 3. Các bước thực hiện

### Bước 1: Tạo file bai08.js

Tạo file bai08.js để viết chương trình sử dụng module fs.

### Bước 2: Chạy chương trình

Sử dụng lệnh:

```bash
node bai08.js
```

### Bước 3: Kết quả thực hiện

- Tạo thư mục data.
- Tạo file ghichu.txt và ghi nội dung.
- Đổi tên thành ghichu_moi.txt.
- Đọc nội dung file sau khi đổi tên.
- Tạo file tam.txt.
- Xóa file tam.txt bằng fs.unlink().
