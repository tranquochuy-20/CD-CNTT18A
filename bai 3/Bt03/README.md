# BÀI 3 - BÀI TẬP 03: LÀM VIỆC VỚI MODULE FS

**Họ và tên:** Trần Quốc Huy

**Lớp:** CĐ-CNTT18A

## 1. Yêu cầu bài thực hành

- Sử dụng module `fs` của Node.js.
- Tạo tập tin `thongtin.txt` chứa họ tên và mã sinh viên.
- Đọc và hiển thị nội dung tập tin lên Terminal.
- Sử dụng `appendFile()` để ghi nối thêm tên lớp.
- Đọc lại tập tin để kiểm tra nội dung sau khi cập nhật.

## 3. Các bước thực hiện

**Bước 1: Kiểm tra phiên bản Node.js**

```bash
node -v
```

**Bước 2: Mở Terminal tại thư mục Bt03**

**Bước 3: Chạy chương trình**

```bash
node bai03.js
```

**Bước 4: Kiểm tra tập tin thongtin.txt**

Mở tập tin `thongtin.txt` để kiểm tra họ tên, mã sinh viên và tên lớp đã được ghi đầy đủ.

## 4. Kết quả thực hiện

Chương trình sử dụng module `fs` để tạo tập tin, đọc nội dung, ghi nối thêm tên lớp và đọc lại nội dung sau khi cập nhật thành công.
