# BÀI 3 - BÀI TẬP 01: QUẢN LÝ DANH SÁCH SINH VIÊN

**Họ và tên:** Huy Trần

**Lớp:** CĐ-CNTT18A

## 1. Yêu cầu bài thực hành

- Khai báo danh sách gồm 5 sinh viên.
- Mỗi sinh viên có mã, họ tên, tuổi và điểm.
- Sử dụng `class` và `constructor` để biểu diễn sinh viên.
- Sử dụng arrow function để lọc sinh viên có điểm từ 5 trở lên.
- Hiển thị danh sách sinh viên đạt yêu cầu bằng `console.log()`.

## 2. Cấu trúc chương trình

- `bai01.js`: Tập tin mã nguồn JavaScript.
- `README.md`: Tập tin mô tả bài thực hành.
- `images/`: Thư mục lưu ảnh chụp các bước và kết quả chạy chương trình.

## 3. Các lệnh thực hiện

**Bước 1: Kiểm tra phiên bản Node.js**

```bash
node -v
```

**Bước 2: Mở Terminal tại thư mục Bt01**

**Bước 3: Chạy chương trình**

```bash
node bai01.js
```

## 4. Kết quả thực hiện

Chương trình lọc thành công các sinh viên có điểm từ 5 trở lên và hiển thị danh sách bằng `console.log()`.

Kết quả gồm 3 sinh viên đạt yêu cầu.
