# BÀI THỰC HÀNH 04 - NODEJS EXPRESS

## 1. Thông tin sinh viên
- Họ và tên: Huy Trần
- Lớp: CD-CNTT18A
- Bài thực hành: Bài 04

## 2. Nội dung thực hành
- Tạo ứng dụng Express.
- Route.
- Middleware.
- Template Engine Pug.
- Error Handling.
- Dự án Calculator theo mô hình MVC.

## 3. Cài đặt

Mở Terminal tại thư mục EXPRESS.

### Khởi tạo
```bash
npm init -y
```

### Cài thư viện
```bash
npm install express body-parser pug
```

## 4. Các lệnh chạy chương trình

### 4.1. Express
```bash
node app.js
```
Truy cập: http://localhost:3000

### 4.2. Route
```bash
node express_route.js
```

- http://localhost:3000
- http://localhost:3000/about
- http://localhost:3000/users?name=Minh

### 4.3. Middleware
```bash
node express_middleware.js
```
Truy cập: http://localhost:3000

### 4.4. Pug
```bash
node express_pug.js
```
Truy cập: http://localhost:3000

### 4.5. Error Handling
```bash
node express_errorhandling.js
```
Truy cập: http://localhost:3000

### 4.6. MVC Calculator
Mở Terminal tại thư mục my-express-app.

```bash
node app.js
```

Truy cập:
http://localhost:3000/calculator
